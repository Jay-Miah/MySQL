# 🛒 SQL Retail & Sales Data Analysis Project  
*A Data Technician Bootcamp Project*

This project demonstrates my ability to query, analyse, and extract insights from retail and sales datasets using **SQL**. It highlights core data‑analysis techniques such as filtering, sorting, aggregating, and joining tables to answer real business questions.

---

## 🚀 Project Overview
The goal of this project was to use SQL to explore retail and sales data, uncover trends, and generate actionable insights. I wrote a series of queries to analyse product performance, customer behaviour, store‑level trends, and time‑based sales patterns.

---

## 🧠 Key SQL Skills Demonstrated

### 🔍 Querying & Data Extraction
- **SELECT** — retrieving relevant fields for analysis  
- **WHERE** — filtering data to focus on specific products, dates, or customer segments  
- **ORDER BY** — sorting results to identify top‑ or bottom‑performing items  
- **GROUP BY** — aggregating data to calculate totals, averages, and trends  
- **JOINs** (INNER, LEFT) — combining tables such as products, stores, and transactions to build richer insights  

---

## 📊 Analytical Use Cases
Using these SQL techniques, I performed analyses such as:

- Identifying best‑selling products and categories  
- Calculating monthly and yearly sales trends  
- Comparing store performance across regions  
- Analysing customer purchasing patterns  
- Creating aggregated metrics for dashboards and reporting  

These queries formed the foundation for deeper data storytelling and business decision‑making.
